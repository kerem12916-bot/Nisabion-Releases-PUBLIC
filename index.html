Professional PDF studio.

Nisabion is a native PDF editing studio for Windows that works entirely on your machine — no accounts, no cloud, no telemetry.

What you can do

✎

Edit existing PDF text

Open a PDF and edit existing text objects in place — with caret, selection, undo/redo and save/reopen.

☑

Interactive AcroForm

Fill text fields, checkboxes, radio groups, combo and list boxes directly inside real PDF forms.

▣

BION projects

Keep edits in a .bion project file — your source PDFs are never modified in place.

⎘

Page tools

Organize pages, insert images, export, and print — with real PDF output, not screenshots.

⛨

Signed updates

A dedicated updater verifies every package with Ed25519 signatures before anything is installed.

◔

Isolated PDF engine

Untrusted PDF parsing runs in a separate worker process, isolated from the main application.

Privacy by design

Offline-first

All document processing is local. The application and its PDF engine make no network connections — the only component with network access is the updater.

No telemetry

No analytics, no tracking, no online accounts. Your documents and personal data never leave your device.

System requirements

  • OS — Windows 10 version 1809 or later, or Windows 11 (64-bit)
  • Memory — ~4 GB RAM recommended
  • Install — per-user installer (no administrator rights) or portable ZIP

Honest beta notes

  • Unsigned binaries. No Windows Authenticode signature yet — SmartScreen may warn about an unknown publisher. Update integrity is unaffected (updates are verified with Ed25519).
  • Forms. Form filling is disabled on PDFs containing digital-signature fields or XFA content (fail-closed by design).
  • Read-only sources. PDF tabs are read-only views; edits are committed through the editing workflow or saved into .bion projects.
  • Beta quality. This is a beta build — feedback and issue reports are welcome on the releases repository.
